# Cómo contribuir

Este manifiesto no busca adhesiones automáticas, sino un diálogo donde se pueda cuestionar cualquier premisa.

1. **Debate:** abre un [Issue](../../issues/new/choose) para señalar un salto lógico, formular una objeción o mostrar un contraejemplo.
2. **Evidencia:** contribuye con estudios primarios, resultados reproducibles, experiencias y fuentes que apoyen **o refuten** la tesis.
3. **Transformación:** edita archivos Markdown directamente desde GitHub y envía un Pull Request con una propuesta de cambio.

## Reglas

- Argumentar sobre ideas, no descalificar personas.
- Separar hechos, hipótesis y posturas normativas.
- Citar la fuente, año, autor y limitaciones de la evidencia.
- Aceptar argumentos contrarios sin borrarlos ni presentarlos como adhesiones.
- Respetar privacidad, derechos de autor y límites de pruebas autorizadas.
- No publicar contraseñas, datos privados ni procedimientos de intrusión a terceros.

El proyecto distingue entre una **propuesta inicial de autor** y un eventual **acuerdo colectivo**, que requerirá un proceso de gobernanza explícito.
