# Manifiesto abierto por una IA y una ciberseguridad colectiva

> **La seguridad no debe ser una excusa para concentrar el poder tecnológico.**

Este repositorio invita a cuestionar una tesis: **la IA debe ser abierta, la seguridad verificable y el poder tecnológico colectivo**. Defender la apertura no equivale a autorizar intrusiones, revelar secretos personales o negar riesgos de uso dual.

**Estado: v0.1 — propuesta inicial de Tomás de Camino Beck; todavía no constituye un consenso comunitario.**

## Una invitación a disentir

**¿Cuál de estos diez principios consideras equivocado y por qué?** Abre un Issue, aporta un contraejemplo o propón una modificación mediante Pull Request. No hace falta saber programar.

Apertura de pesos, código, datos, evaluaciones y gobernanza no son equivalentes. Queremos discutir estas diferencias sin renunciar a la defensa de una IA abierta.
