# Casos reales y límites de las analogías

| Caso | Qué permite discutir | Qué no demuestra |
| --- | --- | --- |
| AES | El mecanismo criptográfico público puede resistir escrutinio. | Que publicar pesos de IA carezca de riesgos adicionales. |
| CrowdStrike (2024) | Riesgos de dependencias compartidas. | Que la centralización sea siempre perjudicial. |
| Log4Shell (2021) | Necesidad de detectar y reparar fallas. | Que la apertura garantice la detección temprana. |
| Linux | Revisión distribuida y modificación. | Que todo el código reciba escrutinio suficiente. |
| Homebrew Computer Club | Apropiación mediante experimentación. | Que la intrusión no autorizada sea legítima. |
| Let's Encrypt | Infraestructura compartida puede reducir barreras. | Que desaparezca la necesidad de gobernanza. |
| Modelos locales | Posibilidad de autonomía y protección de datos. | Que sean seguros, completos o accesibles para todos. |
